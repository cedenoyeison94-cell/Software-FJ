# Sistema Integral de Gestión Software FJ

## Descripción
Software FJ es un sistema desarrollado en Python
para la gestión de clientes, servicios y reservas.

## Objetivo
Implementar una solución orientada a objetos que
permita administrar clientes, servicios y reservas,
aplicando validaciones y manejo de excepciones.

## Tecnologías
- Python
- Programación Orientada a Objetos
- Git
- GitHub
- Visual Studio Code

## Integrantes
Proyecto desarrollado por cinco estudiantes.

## Funcionalidades
- Registro y gestión de clientes.
- Administración de servicios.
- Creación y gestión de reservas.
- Validación de datos.
- Manejo de errores y excepciones.
- Registro de eventos mediante logs.
